> v2「墨夜书房」（墨绿 + 鎏金 + 纸纹 + 印章 + 假封面）已归档为 `DESIGN.v2-墨夜书房.md`。

## v7 改了什么（本轮）

这一版不是视觉改造，是**把「全程离线」这句假话换成一个能选的事实**。云端音色（Edge）原本
无条件开着：设置里没有任何开关，`CloudTts.enabled` 是个全库无人赋值的死字段。于是应用一边在
启动页写「全程离线」、在弹层写「不上传」，一边把每一句正文发到微软。文案已在前一轮改成
「断网可听」，这一轮补上让用户自己决定的那一半。

| 改动 | 位置 |
|---|---|
| 设置页新增「音色」分区：「音色来源」两枚 pill，**自动**（联网用云端、断网用本机）/ **仅本机** | `lib/screens.dart` 的 `_SettingSection(title: '音色')`，复用 `_ChoiceSetting<bool>` |
| 选「仅本机」= 关掉全部出站合成：`CloudTts.available()` 先读设置，false 直接返回，一段都不发 | `lib/cloud_tts.dart` 的 `available()`；删掉死字段 `static bool enabled` |
| 偏好落盘：`cloudAllowed`（`SharedPreferences`），默认 true | `lib/settings.dart` 的 `AppSettings.cloudAllowed` / `setCloudAllowed` |
| 设置页页脚跟着选择变：自动 →「书和进度留在本机。联网用云端音色，断网用本机音色。」；仅本机 →「书、进度和音频都留在本机，合成不联网。」 | `lib/screens.dart` 的 `ValueListenableBuilder` |

顺带（这轮必须一起修的，否则开关本身就是个坑）：

- **云端失败回退时，音频写错了缓存 key**。原来 `dispatch()` 在云端失败后调 `engine.synth(..., outPath: j.cp + '.tmp')`，
  `j.cp` 是 **edge 的缓存路径**；而本机返回的是 f32、云端是 s16，下游又按 `job.cloud` 决定怎么解析——
  等于把一段 Kokoro 的 f32 声音塞进 edge 的 key，下次联网直接命中，时间轴还标「云端音色」。
  现在 `dispatch()` 返回 `_SegOut{reply, cloud, tmp, cp}`，谁合成的就落到谁的 key、按谁的格式解析，
  `segs[].backend` 记的也是实际后端。**这个 bug 在开关之前就存在**，加了开关只是让它更容易被撞上（切来切去必踩）。
- **切换来源时，渲了一半的章整章重来**。一章里前半段云端、后半段本机，是同一本书里两个人轮流念。
  `index.json` 新增章级 `backend` 字段；未渲完且后端不符时清空重渲（音频已在本机的**已完成**章不动，
  也不改它的 `backend`——它确实是云端合成的，播放页那条「云端音色」不能撒谎）。
- **刚从「仅本机」切回自动时立刻重测网络**：`available()` 有 2 分钟 TTL，不失效的话用户切完要等两分钟才生效。
  加 `_lastAllowed` 记住上一次的取值，false → true 时把 `_checkedAt` 清空。

## 0. 为什么改

- 用户是夜里躺床上听的普通人。熄灯后屏幕上最该亮的是**正在读的那句**，不是封面、不是卡片、不是装饰。
- 旧版有三处硬伤：① 播放器把整章三句拼成一段、两端对齐、非当前句压到 26% 灰——几乎读不出来；
  ② 书架用书名哈希生成假封面（导入的 TXT 本来没有封面，画一个等于说谎）；
  ③ `Atmosphere` 墨色渐变 + 金色侧光 + 纸纤维整层是死代码，只增加渲染成本。
- 品牌资产保留：名字「拾声」、宋体书名、橙色（`#E4572E`）作为唯一的"动词色"。

|---|---|---|---|

| `bg2` | `#0F0F0F` | `#F3F2EE` | 画布次层（滚动区底） |

| `danger` / `success` | `#E0574A` / `#7FA894` | `#B03A2E` / `#3F6B57` | 错误、完成 |

规则：

- 一屏金色**最多两处**，且都必须是"此刻正在发生"（当前章、播放进度）。正文永远不上色。
  书库页的橙在 hero 进度条的已播段——那一屏没有别的"正在发生"，所以整屏唯一的橙就是它。
  目录页的橙只在当前章左侧那条整行高的 3px 轨：章号保持 `faint`，否则同一行会把"正在播"说两遍。
- 层次靠**更亮的表面**，不靠阴影。`coverShadow` / `softShadow` 已删除，全库不用 `BoxShadow`。
- **不用大块实心浅色填充**。整屏最亮的东西必须是文字，不是控件：主按钮、播放键、「继续」都是 1–1.5px 描边 + 实心字形，
  不填色。夜里关灯的房间里，一块 300×49 的 `text` 实心矩形是光源，不是按钮。
- 分隔用 0.5px `line`，不用卡片包一层。全库没有"卡片海"。
- 浅色下 `goldBright` 对比度不够，小字一律走 `goldText`（= `goldDeep`）。

| 样式 | 字体 | 字号 / 行高 | 用在哪 |

| `title` | Serif | 21 / 1.35 / 600 | 区块标题、空态标题、弹层标题 |
| `book` | Serif | 17 / 1.45 / 600 | 列表里的书名、章名 |
| `reading` | Serif | 21 / 1.95 / 420 | **播放器正文**（全项目唯一的正文体） |
| `body` | Shisheng Sans | 15 / 1.55 / 480 | 界面正文、按钮下的说明 |
| `bodyStrong` | Sans | 15 / 1.55 / 600 | 强调 |
| `meta` | Sans | 12 / 1.45 / 480 | 章节数、时长、状态 |
| `caption` | Sans | 12 / 1.3 / 560 / ls .8 | 分区标签、注脚、导航标签 |

| `time` | Sans | 12 / 1.4 / 500 + `tabularFigures` | 时间，数字不跳 |
| `readout` | Sans | 17 / 1.4 / 500 + `tabularFigures` | 正在被调整的那个值（语速弹层的大数字），`time` 的同族放大档 |
| `brand` | Serif | 44 / 1.1 / 600 / ls 8 | 只给启动页与启动失败页的品牌字，**不占字阶** |

规则：

- 衬线只负责"书"（书名、章名、正文），无衬线只负责"界面"。两族不混用。
- **变量字体必须同时设 `fontWeight` 和 `fontVariations('wght', n)`**，只给一个整屏会发虚。
- **全站只有 6 档字号**：12 / 15 / 17 / 21 / 28（+ 品牌字 44）。任何地方需要"再小一点"就换字重或颜色，不新开一个字号。
  这条是硬约束：旧版散落 15 个值（9.5 / 10.5 / 11 / 11.5 / 12.5 / 13 / 13.5 / 16 / 20 / 22 / 24 / 26 / 30 / 42 / 44），
  每一处单看都合理，加起来就没有层级了。`grep -rn "fontSize" lib/` 只应命中 `lib/design.dart`——
  别的文件里出现字号 override 就说明有人在偷偷开新档。
- 一屏字号层级 ≤ 4 级；层级靠字号 + 字重 + 颜色三者一起拉，不只靠变灰。
- 报头不抢主角：书架顶部「拾声」用 `title`（21），把 `display`（28）留给正在读的那本书。
- 中文正文**禁止两端对齐**（`TextAlign.justify` 会撑出字间空隙），一律左对齐。
- 中文正文行高 ≥ 1.6；`reading` 给到 1.95，是躺着看也不挤的密度。

## 3. 间距、圆角、动效

- `AppSpace`：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。所有间距只能是这八个数，页面左右边距固定 24。
- `AppRadius`：`cover` 2（进度条、细条）/ `card` 8（按钮、胶囊）/ `sheet` 20（底部弹层）/ `pill` 999。
- `AppMotion`：`fast` 120ms（按压）/ `base` 200ms（状态、正文跟随滚动）/ `slow` 300ms（弹层）/ `hero` 420ms（进入播放器）/ `sleepFade` 20s（睡眠淡出）。
- 只动 opacity 与 transform，不做装饰性循环动画。全库现在**没有**常驻循环动画。

## 4. 每屏一个主角，一个主动作

| 屏 | 主角 | 主动作 | 降级成"壳"的东西 |
|---|---|---|---|
| 书架 | 上次在听的那本书（书名 `display` + 48px 描边播放圆 + 3px 进度条 + 百分比读数） | 继续听（整块可点，不只是圆） | 报头降到 `title`；其他书 → 纯文字行（书名 + `8% · 3 章`），没有封面、没有卡片 |
| 目录 | 章节列表本身（当前章**整行高的 3px 橙轨** + 副行「正在播放」） | 点章播放 | 书名、统计、继续收听行都退到上面一小块；章号恒 `faint`，不再上橙；「优先合成」`muted`，不许比当前章亮 |
| 播放器 | **正在读的那一段正文**（当前句 100% 白，同段其余句 muted） | 播放 / 暂停 | 章名、进度、时间、倍速全部是安静的壳 |

- 播放器正文按**段落**排：段间 12px，段首两个全角空格缩进，只显示当前段前后各 2 段（总句数封顶 30）。
  段落边界由句间停顿推断（`gap >= 300ms` 视为换段，因为渲染时的 `pausePara = 0.35s` 远大于句间 `0.06s`），
  对白以 `“` / `「` 起头且上一句以 `。！？”」` 收尾时也单独成段。
- 当前段会自动滚到视口 34% 高度处（`Scrollable.ensureVisible`，200ms）；段落不满一屏时整体垂直居中，不留死白。
- 书架**不生成封面**。导入的 TXT 没有封面，画一个就是编；书靠名字和进度被认出来。
- 目录页**不做整体垂直居中**。居中会让「聊斋志异·卷一」在三章的书里停在 y233、在八章的书里停在 y97——
  同一个书名在同一个页面里不该有两个高度。三章的书下面空着，那是因为它真的只有三章，不是排版没写完。
  超过 40 章走 `SliverList` 按需构建（长列表不该一次性全部建出来）。
- 书库的「导入」块钉在栏底（`SliverFillRemaining(hasScrollBody: false)`）：书只有三本时压住屏幕下缘，
  书多时排在列表末尾。跟着最后一行浮在半空会让整屏像没写完。

## 6. 状态（数据区五态齐全）

- **空**：`_FirstRunEmptyState`「书架空空」+ 一句能做什么 + 唯一主按钮「导入 TXT」（铺满栏线 x24–366）+ 次要文字链「怎么听？」（带 `faint` 下划线——无标记的同灰文字既不像链接也不像按钮）。
- **加载**：22×22 转圈（stroke 2，`gold`），不铺骨架屏——本地读取通常 < 200ms。
- **错误**：`main.dart` 启动失败页写清**原因 + 出路**（「引擎初始化失败：… 清后台后重试通常可解；仍不行请告诉我机型。」），不道歉、不甩代码。
- **有数据**：hero + 列表。
- **完成**：不额外提示。合成完了，播放页中间那格就空着——「本章已完整合成」是句废话，
  它只在还没好（「边播边合成 7/12 块」）或音色来自云端（「云端音色」）时才有话说。
- **进行中**：导入时页脚显示「正在导入…」；目录每章副行写清时长 + 状态（「8 分 12 秒 · 正在播放」/「10 分 4 秒 · 合成中 58%」/「11 分 38 秒」），
  未合成的章右列给文字链「优先合成」（只放箭头要人猜）。时长来源：已合成读 `index.json` 的 `total_ms`，合成中读 `est_ms`，
  没动过的按 `estSec()` 累加（4.3 字/秒，和合成引擎同一个常数）。

## 7. 文案

- 控件写动作：「继续」「导入 TXT」「目录」「定时」「选择 TXT 文件」。
- 状态写事实与出路：「已插队，稍等几秒就会开始」「已回退 5 秒，接上刚才那句」。
- 不用 eyebrow、不用 01/02/03 编号、不用 emoji 当图标、不写"示例/示意图"这类制作说明。
- 界面文案与实际能力一致：导入只支持 TXT，就只写 TXT（旧版写「txt / epub」是错的）。
- **不说「全程离线」，说「断网可听」**。云端音色是联网的，写「全程离线」就是假话；「断网可听」是真的：
  断网时它退到本机音色，照样能听。设置页页脚同理——选了「仅本机」才说「合成不联网」，没选就别替用户保证。

## 8. 无障碍

- 触达：所有图标按钮 44×44 起（`_TopIcon`、`_NavItem`、迷你条播放钮），主按钮 48 高，章节行 76 高，播放页 tab 行 48 高，播放主控 56。
  「继续」的描边圆在书架 hero、目录页是同一个 48。
- 播放页 tab 行（倍速 / 定时 / 设置 / 目录）用 `body` 15 档、未选中 `muted`：这是躺下以后按得最多的四个键，不能是小字。
- 「优先合成」用 `muted`（暗底 7.19:1）而不是 `text`：动作通常比数据亮，但目录页的主角是**正在播的那一章**，
  别的行的动作不该比它亮。全站唯一的例外，理由写在这里，不要顺手改回去。
- 对比（WCAG 实测）：暗色 `text/bg` 17.71:1、`muted/bg` 7.19:1、`faint/bg` 5.13:1、`whisper/bg` 4.59:1、`gold/bg` 5.38:1；
  浅色 `text/bg` 17.50:1、`muted/bg` 7.83:1、`faint/bg` 5.17:1、`whisper/bg` 4.60:1。四档灰全部过 AA，正文只有两档（当前句 / 其余）。
  浅色 `muted` 从 `#5F5F58`（6.11）提到 `#4F4F49`（7.83）：原来它和 `faint`（5.17）只差 0.9，四级灰实际只有三级。
- 四级文字各司其职：`text` = 可读内容，`muted` = 正文与非当前句、读数，`faint` = 分区标签、副行、编号、未选中导航，
  `whisper` = 只给隐私脚注。**不靠 alpha 叠色造灰**，每一档都是实色 token。
  （曾试过更暗的 `#6E6E68`（暗）/ `#8A8A82`、`#9A9A92`（浅）做第四档，实测 3.86 / 3.30 / 2.69:1，不过 AA，已弃用。）
- 分隔线（`line` 暗 2.31 / 亮 2.10:1）与进度槽（`track` 暗 3.05 / 亮 3.28:1）是**非文字图形**，不适用 4.5:1；`track` 做到 3:1，因为「还剩多久」必须看得见长度。播放页进度条右端另加 1×9px 终点刻度。
- 语义：`Semantics(button/label/selected)` 覆盖播放圆、迷你条、导航项；播放器主控有「播放 / 暂停」标签。
- 文字缩放支持到 2.0；`library` / `detail` / `player` 三页有 2.0 冒烟测试。
- 安全区：三页 `SafeArea(bottom: false)`，底部条自带 `SafeArea(top: false)`。
