# 拾声 · CAST CLUB 设计说明

> 这一版不是给旧听书界面换色，而是把产品骨架改成「角色优先」。
> 一句话：**先认识角色，再开始听。**

## 产品结构

主导航只有三段：

1. **阵容**：今晚听谁。当前书、当前幕、这一场的角色卡和接下来的场次。
2. **剧本**：这本小说怎么排。每本剧本的角色表、分镜和合成状态。
3. **试镜**：每个角色一张声卡。旁白/对白和音色来源在这里收口。

进入播放后，页面从「一章正文」变成「谁在说话」：当前说话的人站到前面，
旁白退成浅紫卡片，下一句缩进柠檬黄气泡里等待。

旧版的「书架 → 目录 → 播放」不再作为首页心智。数据层和播放器仍然是原来的
可靠链路，改变的是用户先看到什么、先理解什么。

## 视觉方向

### 颜色

| Token | 浅色舞台 | 用途 |
|---|---|---|
| `bg` / `bg2` | `#FBF7FF` / `#F3ECFF` | 浅紫白画布 |
| `lilac` | `#C9B7FF` | 旁白、背景块、角色底 |
| `coral` | `#FF6752` | 当前角色、主要动作 |
| `lemon` | `#FFE347` | 下一句、提示、强调 |
| `mint` | `#78EBCE` | 已就绪、次要状态 |
| `outline` | `#302A3A` | 粗描边、硬阴影 |

深色主题是可选「夜场」，把同一组四色压到深紫底上。默认进入浅色舞台，
用户可在设置里切到浅色、跟随系统或暗场。

### 字体

- 标题 / 角色名 / 场景名：`ZCOOL KuaiLe`，有手写漫画感，但不幼稚。
- 正文 / 按钮 / 读数：`ShishengSans`，中文正文优先保证长句可读。
- 字体路由统一在 `lib/design.dart` 的 `AppType`，页面不直接写字体族。

### 形状与动作

- 主卡片 18px 圆角、2–2.5px 深色描边、无模糊硬阴影。
- 标签用胶囊，角色头像用文字色块，不生成假封面、不上真人照片。
- 动效只反馈状态：按下、导入、合成进度、播放。没有常驻装饰动画。

## 每屏主角

| 屏 | 主角 | 主动作 |
|---|---|---|
| 启动 | 「拾」字舞台 + 产品一句话 | 等模型就绪 |
| 阵容 | 当前在听的那本书和这一场的角色 | 继续听 / 翻剧本 |
| 剧本库 | 剧本本身 | 翻到想听的那一幕 |
| 分镜 | 当前幕和角色表 | 继续听 / 优先合成 |
| 对白 | 正在说话的人 | 播放 / 暂停 / 前后跳 |
| 试镜 | 每个角色的声卡 | 切换音色来源 |

## 数据真实性

- 阵容人数和角色出场数从 `BookIR.chapters[].segments` 的真实说话人统计，
  不按书名或封面编造。
- 试镜页没有伪造的单角色试听按钮。现有音频管线以章为单位合成，界面不假装
  已经支持逐角色即时试听。
- 合成状态、百分比、已存时长来自原来的 `render` / `playback` 状态机。
- 导入、删除、插队合成、VoiceStudio 设置仍走原有逻辑；重构只改呈现层，
  没有把真实能力换成静态样稿。

## 响应式与无障碍

- 支持 2 倍文字缩放；阵容、剧本库、分镜、试镜、对白各有 2.0 冒烟测试。
- 320×568 窄屏和 844×390 横屏有布局冒烟测试，不比较像素。
- 图标按钮保持至少 44×44 命中区；正文禁止两端对齐；中文正文行高 ≥1.5。
- 粗描边和硬阴影用于分区，不依赖低对比灰线；正文色和动作色分别过可读性检查。

- 中文衬线正文和「书卷」标题层级。

- 旧 `test/goldens/` 中的报纸版截图基线。
